AI 대전 기록 1.3
================

Windows용 독립 실행 프로그램입니다. Excel, Python, 별도 설치, 인터넷 연결이 필요하지 않습니다.
Windows 10/11의 .NET Framework 4.x를 사용합니다.

실행
----
AI대전기록.exe를 더블클릭하세요.

경기 기록
---------
1. 경기 날짜와 대전 상대를 입력합니다.
2. 시간을 분:초로 입력합니다. 예: 8:35는 8분 35초입니다.
   1시간 이상은 1:02:30처럼 시간:분:초로 입력해도 됩니다.
3. 내 기준으로 승리 / 패배 / 무승부를 선택합니다.
4. 필요한 경우 메모를 적고 '기록 추가'를 누릅니다.

상대 이름은 이전에 입력한 목록에서 다시 고를 수 있습니다.
승패는 자동 감지하지 않습니다. 사용자가 직접 입력합니다.

타이머 (선택)
-------------
'타이머 시작' → 경기 종료 시 '타이머 정지' → 승패 선택 → 기록 추가.
직접 입력한 시간이 있으면 그 시간부터 이어서 측정합니다.
정지 중에는 시간을 직접 고칠 수 있습니다.
'초기화'는 현재 입력 중인 시간만 00:00으로 바꿉니다.
타이머는 실제 경과 시간을 측정합니다. 게임 일시정지나 배속을 자동 반영하지 않습니다.

조회와 통계
-----------
상단에서 전체 기록 / 월별 / 날짜별을 선택합니다.
검색창으로 상대 이름 또는 메모를 검색할 수 있습니다.
총 경기 수, 승패, 승률, 누적 시간은 현재 조회·검색 결과를 기준으로 계산합니다.

경기 기록: 날짜별 회차, 상대, 시간, 승패, 메모.
날짜별 합계: 하루 경기 수, 승패, 승률, 누적 시간, 평균 시간.
상대별 통계: 상대별 경기 수, 승패, 승률, 누적 시간, 평균 시간.

승률 = 승 / (승 + 패). 무승부는 승률 계산에서 제외합니다.
승패 기록이 없으면 승률은 '—'로 표시합니다.
누적 시간은 저장된 경기 시간의 합계이며, 경기 사이 휴식은 포함하지 않습니다.
회차는 날짜별 기록 생성 순서입니다.

전체 기록을 넓게 보기
--------------------
상단 '전체 기록 보기'를 누르면 입력칸 없는 전체 화면이 열립니다.
'날짜별 모아보기'는 날짜마다 상대·시간·승패를 나란히 보여줍니다.
'전체 목록'은 모든 경기와 메모를 하나의 표로 보여줍니다.
기록이 많으면 스크롤해서 계속 볼 수 있습니다.
전체 기록 화면은 메인 화면의 날짜 필터와 관계없이 모든 기간을 보여줍니다.
이 화면의 검색창으로 상대 이름이나 메모를 찾을 수 있습니다.
상단 '표 너비' 슬라이더로 날짜별 표를 200~520px 사이에서 조절할 수 있습니다.
왼쪽으로 움직이면 표가 좁아져 더 많은 날짜를 나란히 볼 수 있습니다.
'기본' 버튼은 표 너비를 280px로 되돌립니다. 조절한 너비는 다음 실행에도 유지됩니다.
긴 상대 이름은 마우스를 올리면 전체 이름을 확인할 수 있습니다.
전체 기록 창을 복원한 뒤 가장자리를 드래그하면 가로 620px까지 줄일 수 있습니다.

메모장으로 내보내기
------------------
1. 경기 기록 표 바로 위의 '메모장 내보내기 ▾'를 누릅니다.
2. '전체 기록 내보내기' 또는 '현재 조회·검색 결과 내보내기'를 고릅니다.
3. 저장 위치와 파일 이름을 정하면 TXT 파일이 만들어집니다.
4. 저장한 TXT를 더블클릭하거나 메모장에서 열어 확인하세요.

전체 합계와 날짜별 합계, 상대·경기 시간·승패·메모가 포함됩니다.
날짜는 최신 날짜부터, 같은 날짜 안의 경기는 기록 생성 순서로 정렬합니다.
한글이 유지되도록 UTF-8로 저장합니다.
메모에 들어 있는 줄바꿈과 탭은 각각 \\n, \\r, \\t로 표시됩니다.
내보내기는 저장된 경기 기록만 대상으로 하며 입력 중인 내용은 포함하지 않습니다.
TXT를 v1.2 이상의 '메모장 가져오기'에서 다시 읽을 수 있습니다.
빠짐없는 원본 보관과 PC 이동용으로는 JSON 백업도 함께 사용하세요.

메모장 기록 가져오기
-------------------
1. 상단 '메모장 가져오기'를 누릅니다.
2. 내용을 붙여넣거나 'TXT 파일 열기'를 누릅니다.
3. 날짜가 적혀 있지 않은 경기의 기본 날짜를 선택합니다.
4. '아래 표로 변환'을 누릅니다.
5. 표에서 날짜·상대·시간·승패·메모를 확인하고 필요하면 고칩니다.
6. 추가할 줄을 체크한 뒤 '선택 기록 저장'을 누릅니다.

지원 형식 예:
2026-10-24
플루토 8:35 승
AI 6:35 패
2026-10-23, 플루토, 07:12, 패
10/22
플루토 7분 5초 무승부 # 맵 이름이나 메모

날짜만 적힌 줄은 아래 경기들에 적용됩니다.
월/일만 적으면 선택한 기본 날짜의 연도를 사용합니다.
날짜가 없으면 기본 날짜를 사용하므로 저장 전에 꼭 확인하세요.
'#' 뒤의 내용은 메모로 넣습니다.
승/패/무, 승리/패배/무승부, win/loss/draw를 읽을 수 있습니다.
시간은 분:초, 시간:분:초 또는 '7분 5초'처럼 입력할 수 있습니다.
한 줄은 한 경기로 해석합니다.
해석하지 못한 줄은 원문과 확인 사항을 표시하고 추가 체크를 해제합니다.
원문은 미리보기의 '원문' 열에서 확인할 수 있습니다.
기존 기록과 날짜·상대·시간·승패·메모가 같은 줄은 기본 해제됩니다.
실제로 별개의 경기라면 직접 체크해서 추가할 수 있습니다.
TXT는 UTF-8, UTF-16(BOM), 한글 CP949를 지원합니다.
원본 메모장 파일은 변경하지 않습니다. 실시간 자동 동기화가 아닌 확인 후 가져오기입니다.

수정과 삭제
-----------
경기 기록 탭에서 행을 선택하고 '선택 기록 수정' 또는 '선택 기록 삭제'를 누릅니다.
행을 더블클릭해도 수정할 수 있습니다.
수정은 '수정 저장'을 눌러야 반영됩니다. '수정 취소'로 취소할 수 있습니다.

자동 저장과 백업
----------------
추가·수정·삭제는 즉시 자동 저장됩니다. 저장 실패 시 메시지가 나오고 입력 내용이 유지됩니다.
기록 위치: %LOCALAPPDATA%\AiMatchLog\records.json
직전 저장 상태: 같은 폴더의 records.json.bak

'백업 저장'으로 전체 기록을 JSON 파일로 보관할 수 있습니다.
'백업 불러오기'는 현재 기록에 백업의 새 기록을 합칩니다.
같은 ID의 기록은 중복 추가하지 않고 현재 기록을 유지합니다.
새 PC로 옮기거나 Windows를 다시 설치하기 전에는 백업 파일을 별도로 보관하세요.
입력만 하고 '기록 추가'를 누르지 않은 내용은 저장된 경기 기록이 아닙니다.

기존 자료
---------
첨부 화면 사진의 구조를 참고해 만든 프로그램입니다.
사진 속 과거 경기 기록은 자동 입력하지 않았습니다.
엑셀 원본 가져오기 기능은 포함하지 않았습니다.

개인정보와 연결
--------------
서버 연결, 계정 로그인, 외부 전송, 경기 자동 감지는 없습니다.
프로그램을 다른 폴더로 옮겨도 같은 Windows 사용자 계정의 자동 저장 기록을 사용합니다.

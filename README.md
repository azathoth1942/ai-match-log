# AI 대전 기록

Windows에서 AI 대전 상대, 경기 시간, 승패를 직접 기록하는 프로그램입니다. Excel이나 인터넷 연결 없이 실행할 수 있습니다.

## 다운로드 및 실행

[AI대전기록.exe 다운로드](dist/AI대전기록.exe?raw=1)

파일을 다운로드한 뒤 더블클릭하세요. Windows 10/11의 .NET Framework 4.x를 사용하며 별도 Python 설치는 필요하지 않습니다.

## 주요 기능

- 경기 날짜, 상대, 시간, 승패, 메모 입력 및 수정
- 선택적으로 사용하는 시작·정지 타이머
- 날짜별 경기 수, 승패, 승률, 누적·평균 시간
- 상대별 통계와 검색
- 날짜별 표와 전체 목록으로 보는 전체 기록 화면
- 메모장 붙여넣기 및 TXT 가져오기와 미리보기
- 전체 기록 또는 현재 조회 결과를 TXT로 내보내기
- 변경 즉시 자동 저장, JSON 백업 및 복원

승패는 **내 기준**으로 입력합니다. 승률은 `승 / (승 + 패)`이며 무승부는 제외합니다. 누적 시간은 기록한 경기 시간의 합계입니다.

## 사용 순서

1. 날짜와 대전 상대를 입력합니다.
2. 시간을 `8:35`처럼 분:초로 입력하거나 타이머로 측정합니다. 한 시간 이상은 `1:02:30`도 사용할 수 있습니다.
3. 승리·패배·무승부를 선택하고 **기록 추가**를 누릅니다.
4. 상단의 **전체 기록 보기**에서 모든 날짜의 기록을 넓게 확인합니다.

경기 기록 표 위의 **메모장 내보내기 ▾**에서 TXT를 저장할 수 있습니다. TXT는 v1.2 이상의 **메모장 가져오기**에서 다시 읽을 수 있습니다.

자세한 내용은 [사용방법](docs/사용방법.txt)을 참고하세요.

## 메모장 입력 예시

```text
2026-10-24
플루토 8:35 승
AI 6:35 패
2026-10-23, 플루토, 07:12, 패
플루토 7분 5초 무승부 # 맵이나 특이사항
```

한 줄에 한 경기씩 입력합니다. 날짜만 적힌 줄은 다음 경기들의 날짜로 적용됩니다. 가져오기 미리보기에서 해석 결과를 확인하고 수정한 뒤 저장하세요.

## 기록 보관

기록은 사용하는 Windows 계정의 다음 위치에 저장됩니다.

```text
%LOCALAPPDATA%\AiMatchLog\records.json
```

직전 저장본은 `records.json.bak`에 보관합니다. 다른 PC로 옮길 때는 **백업 저장**으로 만든 JSON 파일을 함께 옮기세요. 백업 불러오기는 현재 기록에 새 기록을 합치며 같은 ID는 중복 추가하지 않습니다.

계정 로그인이나 서버 전송, 게임 결과 자동 감지 기능은 없습니다. 이 저장소에는 프로그램 소스와 배포 EXE만 포함하며 개인 경기 기록은 포함하지 않습니다.

## 소스에서 빌드

Windows PowerShell에서 저장소 폴더를 열고 실행합니다.

```powershell
.\build.ps1
```

결과는 `bin\AI대전기록.exe`입니다. Windows에 포함된 .NET Framework C# 컴파일러를 사용합니다.

저장·통계·TXT 변환 및 UI 바인딩 검사를 함께 실행하려면:

```powershell
.\build.ps1 -Test
```

검사 결과와 검사용 이미지는 `.test`에 생성되며 Git에서 제외됩니다. 배포용 EXE도 갱신하려면 `-Release`를 추가합니다.
